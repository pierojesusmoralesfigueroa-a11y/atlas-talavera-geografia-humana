# Publicación Atlas Talavera V13

1. Descarga y extrae `Actualizacion_Talavera_V12_a_V13.zip`.
2. Comprueba que el repositorio destino sea **atlas-talavera-geografia-humana**, NO `atlas-lima-satipo-2026`.
3. Abre https://github.com/pierojesusmoralesfigueroa-a11y/atlas-talavera-geografia-humana/upload/main
4. Arrastra TODOS los archivos y carpetas extraídos. Mantén las rutas `assets/laminas/`, `assets/laminas_pdf/`, `assets/turismo_fotos/` y `data/`.
5. Haz **Commit changes** con el mensaje `Atlas Talavera V13 - Integración de láminas M10 M11 M12`.
6. En Actions verifica que `pages build and deployment` finalice con éxito.
7. Abre https://pierojesusmoralesfigueroa-a11y.github.io/atlas-talavera-geografia-humana/?v=13 y pulsa Ctrl + F5.
8. Comprueba M10: alternar quechua/castellano; M11: cinco recursos, tres fotos; M12: estimación/grupos; consulta y descarga de PDF A3 en los tres mapas.

**Nota:** los PDF A3 se han incluido en la actualización. Ninguno excede el límite de 25 MB por archivo de la carga web de GitHub. Si la carga no conserva las carpetas, usa GitHub Desktop para copiar el contenido descomprimido al repositorio.

**Procedencia de fotografías:** la lámina M11 fue suministrada por el autor del proyecto; verificar derechos de las fotografías antes de mantener el sitio como público.
